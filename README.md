Sorting Algorithm

Program Description
Kani nga Java program kay ga arrange og 10 ka numbers gikan sa pinakagamay hangtod sa pinakadako gamit ang Bubble Sort, Selection Sort, ug Insertion Sort.

Bubble Sort: Mag compare sa ga tapad nga numbers ug mag ilis sa ilang position kung dili sakto ang order, like if mas dako ang number sa left kaysa sa right, then ibaylo nila ang ilang position. Balik balikon ra ang pag compare ug pag swap hangtod ma arrange ang tanan numbers.
 

Selection Sort: Mangita sa pinakagamay nga number sa array ug ibutang dayon sa sakto nga position, like if makita naniya ang pinaka gamay then ibutang niya sa pinaka unahan. Balik balikon niya hangtod ma arrange tanan numbers.


Insertion Sort:  Magsugod sa ikaduha nga number ug i compare niya sa mga numbers nga naa sa left. Kung mas dako ang mga nag unang numbers, ibalhin niya sa right para masulod ang current number sa sakto nga position. mag continue rani  hangtod ma arrange ang tanan numbers.

 Differences Between the Three Algorithms

Ang Bubble Sort mag compare sa ga tapad nga numbers. Ang Selection Sort mangita sa pinakagamay nga number. Ang Insertion Sort magbutang sa number sa sakto nga position. Bisag lahi lahi ilang pamaagi, ang each algorithm kay naay own nga process sa pag arrange sa numbers gikan sa pinakagamay hangtod sa pinakadako.

Reflection Questions

1. How does each sorting algorithm arrange numbers, and what makes their processes different?

Ang Bubble Sort ga swap sa ga tapad nga numbers, ang Selection Sort mangita ug mopili sa pinakagamay, while ang Insertion Sort mag shift ug mosulod sa number sa sakto nga place. Lahi ang ilang pamaagi sa pag-arrange sa numbers.

2. Among the three sorting algorithms, which one do you think is the easiest to understand and implement? Why?

For me, Bubble Sort ang pinakasayon kay simple ra ang pag compare ug pag swap sa ga tapad nga numbers.

3. If the numbers are already sorted, which algorithm do you think would perform better? Explain your answer based on how the algorithms work.

Insertion Sort ang mas better kay isa ra ka comparison ang buhaton sa kada ga sunod nga number kung sorted na daan ang array.

4. What will happen if you add more numbers to your array? How might this affect the performance of each sorting algorithm?

Kung mas daghan ang numbers sa array, mas daghan pud ang steps nga kinahanglan buhaton sa sorting algorithms. Ang Bubble Sort ug Selection Sort mag need og daghang comparisons, while ang Insertion Sort need og dugang shifting kung daghan ang numbers nga wala pa na arrange. Mas paspas gihapon ang Insertion Sort kung hapit na sorted ang array.

5. As a future programmer, why is it important to understand different sorting algorithms instead of using just one?

As a future programmer, important jud nga masabtan ang lain laing sorting algorithms kay makatabang ni nato nga maka pili sa pinaka maayong way sa pag sort depende sa situation. Dili man gud parehas ang performance sa kada algorithm, labi na kung modaghan ang data.
